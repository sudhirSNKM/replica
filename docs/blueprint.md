# **App Name**: Replica

## Core Features:

- User Authentication & Profile Management: Secure user registration, login, logout functionalities, and the ability for users to manage and switch between multiple personalized profiles, with data stored in Firestore.
- Dynamic Content Browsing: Explore an extensive library of movies and series categorized by trending, top picks, and various genres, powered by metadata retrieved from Firestore.
- Watchlist & Continue Watching: Users can add content to a personalized watchlist and seamlessly resume playback from where they left off across devices, with all states and timestamps managed in Firestore.
- Immersive Video Playback: A feature-rich video player with auto-play, resume playback, skip intro, and fullscreen capabilities, streaming assets served from Firebase Storage.
- Cinematic Smart Hero Section: An advanced, interactive hero section with dynamic content updates, immersive hover effects (including muted video previews), parallax mouse movement, and adaptive background changes.
- Admin Content Management: An administrative interface for content curators to upload and manage movie metadata (title, genre, thumbnail, video URL) directly into the Firestore database.
- AI-Powered Recommendations Tool: An intelligent recommendation tool (with dummy logic for the MVP) that will suggest personalized movies and shows to users, leveraging generative AI principles to curate content suggestions.

## Style Guidelines:

- Primary color: Vivid Electric Blue (`#297AF7`), chosen for its futuristic appeal and dynamic contrast against dark backgrounds.
- Accent color: Vibrant Neon Magenta (`#E633CC`), providing a 'neon glow' effect and serving as a striking highlight for interactive elements.
- Background layers: A deep, near-black (`#0B0B0F`) acts as the ultimate cinematic canvas, complemented by dark, desaturated blue-grey (`#181E24`) for UI elements to provide depth and harmonize with the primary hue.
- Headlines and prominent text: 'Space Grotesk' (sans-serif) for a modern, tech-inspired feel. Body text and smaller UI elements: 'Inter' (sans-serif) for optimal readability and a neutral aesthetic.
- Sleek, minimalist line-art icons that integrate seamlessly with the glassmorphism aesthetic. Icons should feature subtle glowing effects on interaction, mirroring the premium UI design.
- A layered, spacious layout emphasizes depth through glassmorphism (blur + transparency), rounded cards with soft shadows, and subtle floating elements. The Hero section employs parallax for interactive depth.
- Fluid, advanced animations powered by Framer Motion and GSAP, including dynamic content transitions, interactive hover effects (scaling, glowing, video previews), and sophisticated page load and scroll behaviors for an engaging user experience.
